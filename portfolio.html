Talk or Type to Your Database

Python, Streamlit, OpenAI function calling, Whisper, TTS, Supabase PostgreSQL

Ask a question about business data by voice or text, in English or Arabic, and hear a short answer backed by real SQL. The AI agent reads the database schema, writes and runs the query, and fixes its own SQL if it fails. A read-only database user, SELECT-only validation and query timeouts keep the data safe, and every answer shows the exact SQL behind it.
